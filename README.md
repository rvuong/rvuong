that let a team grow. That's where my energy goes.

## What I'm building

- **[email-assistant](https://github.com/rvuong/email-assistant)** —
  A Rust daemon that turns an inbox into an action engine: send an
  email, trigger an API call. Built before agentic AI was a thing —
  the intuition was right, the timing was early.
- **[rust-imap](https://github.com/rvuong/rust-imap)** —
  Fork of jonhoo/rust-imap. Extended to fit the needs of
  email-assistant.
- **[game_of_life](https://github.com/rvuong/game_of_life)** —
  Conway's Game of Life in Rust CLI. A learning exercise,
  kept simple on purpose.
- **[rpi_quote](https://github.com/rvuong/rpi_quote)** —
  A Python app running on a Raspberry Pi. Fetches a daily quote
  from an API, translates it to French, and renders it on an
  e-ink display — with adaptive typography based on text length.
  Runs on a cron, stays on all day without power. A different
  stack, the same attention to detail.
